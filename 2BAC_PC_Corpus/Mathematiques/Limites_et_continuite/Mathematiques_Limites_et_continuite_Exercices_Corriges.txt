## SÉANCE 1 — Exercices (Rappel limites et dérivation)

### Exercice 1
Soit f : x ↦ (x+1)² / |x² − 1|

1. Étudier la limite de f en x₀ = −1
2. Calculer :
A = lim_{x→+∞} (x² − √x)
B = lim_{x→1} (x³+1)/(x−1)²
C = lim_{x→+∞} (x³+1)/(x−1)²
D = lim_{x→+∞} (2x³ + x² − x + 4)
E = lim_{x→1+} (3x+1)/(x²+x−2)
F = lim_{x→+∞} (2x + 5x² − 7x⁴)
G = lim_{x→+∞} (2x+5x²−7x⁴)/(x−10x²+14x³)
H = lim_{x→+∞} (3x+8x²−2x⁵)/(x²+2x⁶)
I = lim_{x→1−} (3x²−x)/(2x³+2x−4)
J = lim_{x→2} (√(4x+1)−3)/(x²−3x+2)

### Indications / Corrigé (méthodes)
A : facteur dominant x² → +∞
B : (x−1)² au dénominateur, numérateur → 2, forme 2/0+ → +∞ (ou étudier signe)
C : quotient termes haut degré → +∞
D : terme dominant 2x³ → +∞
E : numérateur → 4, dénominateur → 0+ (car x→1+, x²+x−2=(x+2)(x−1)→0+) → +∞
F : −7x⁴ dominant → −∞
G : quotient (−7x⁴)/(14x³) → −∞
H : (−2x⁵)/(2x⁶) → 0
I : num→2, dén→0− → −∞
J : forme 0/0, rationaliser numérateur et factoriser dénominateur (x−2)(x−1)

### Exercice 4
Déterminer f' et étudier la monotonie :
1. f(x) = x² + 3x + 1
2. f(x) = √x + x³
3. f(x) = (4x−3)/(2x−1)
4. f(x) = √(x²−4)

Corrigé résumé :
1. f'(x)=2x+3 ; f'≥0 sur [−3/2,+∞[ → croissante ; décroissante sur ]−∞,−3/2]
2. f'(x)=1/(2√x)+3x² > 0 sur ]0,+∞[ → strictement croissante
3. f'(x)=−2/(2x−1)² < 0 → strictement décroissante sur chaque intervalle de D_f
4. D_f=]−∞,−2]∪[2,+∞[ ; f'(x)=x/√(x²−4) ; croissante sur [2,+∞[, décroissante sur ]−∞,−2]

## SÉANCE 2 — Exercices continuité

### Exercice 1
Étudier la continuité de f en x₀ dans les cas :
a) x₀=5, f(x)=(x²−2x−15)/(x²−25) pour x≠±5, f(5)=8
b) x₀=−1, f(x)=2/(x³+1) pour x≠−1, f(−1)=3
c) x₀=3, f(x)=(√x−√3)/(x−3) pour x∈[0,+∞[\{3}, f(3)=1/(2√3)

Soit f définie par :
f(x)=1/(x+1) si 0≤x<1/2
f(x)=2x+a x² si 1/2≤x≤1
Déterminer a pour que f soit continue en x₀=1/2.

### Exercice 2
f définie sur [2,+∞[ par f(x)=(x²−4)/(x−2) si x>2, f(2)=4
Étudier la continuité sur [2,+∞[.
Corrigé : lim_{x→2} (x+2)=4=f(2) → continue en 2 ; rationnelle ailleurs → continue sur [2,+∞[.

### Exercice 5
f(2)=4 et f(x)=(x³−8)/(x²−x−2) si x≠2
1. D_f = ℝ\{−1} (après simplification, x=2 est une singularité apparente)
2. Continuité en 2 : lim = 4 = f(2)
3. ∀x≠−1, f(x)=(x²+2x+4)/(x+1)
4. Continue sur ]−∞,−1[ et ]−1,+∞[

### Exercice 5
f(x)=x³−x²+3x+1
1. f'(x)=3x²−2x+3 = 3(x−1/3)² + 8/3 > 0 → strictement croissante
2. f(−1/2)<0, f(0)>0 → unique racine dans ]−1/2, 0[ (TVI + stricte mono)
3. Encadrement par dichotomie

### Méthode générale (dichotomie)
Si f continue, f(a)f(b)<0, strictement monotone :
- m = (a+b)/2
- si f(a)f(m)≤0 alors racine dans [a,m], sinon dans [m,b]
- répéter jusqu'à amplitude voulue

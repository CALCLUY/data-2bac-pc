## Exercice 1 : Fonctions numériques (2 pts)

a. Résoudre dans ℝ l'équation e^{2x} − 4e^x + 3 = 0

b. Résoudre dans ℝ l'inéquation e^{2x} − 4e^x + 3 ≤ 0

c. Calculer lim_{x→0} (e^{2x} − 4e^x + 3)/(e^{2x} − 1)

2. Montrer que l'équation e^{2x} + e^x + 4x = 0 admet une solution dans l'intervalle [−1, 0] (intervalle à confirmer selon énoncé officiel).

## Exercice 2 : Suites numériques (4 pts)

Suite (u_n) définie par :
u_0 = 1/2
u_{n+1} = u_n / (3 − 2 u_n)  pour n ∈ ℕ

1. Calculer u_1

2. Montrer par récurrence que pour tout n ∈ ℕ, 0 ≤ u_n ≤ 1/2

3. a. Montrer que pour tout n, u_{n+1}/u_n ≤ 1/2
   b. En déduire la monotonie de (u_n)

4. a. Montrer que pour tout n, 0 ≤ u_n ≤ (1/2)^{n+1} ; puis calculer lim u_n
   b. On pose v_n = ln(3 − 2 u_n) ; étudier/calculer des propriétés de (v_n)

5. a. Vérifier que pour tout n, 1/u_{n+1} − 1 = 3(1/u_n − 1)
   b. En déduire u_n en fonction de n

## Exercice 3 : Nombres complexes (5 pts)

1. Résoudre dans ℂ : z² − √3 z + 1 = 0

2. Soient a = e^{i π/6} et b = 3/2 + i √3/2
   a. Écrire a sous forme algébrique
   b. Vérifier que ā · b = √3

3. Dans le plan complexe, points d'affixes liées à a, ā, b
   Montrer qu'un point est l'image d'un autre par une homothétie de centre O (rapport à déterminer)

4. Rotation de centre O et d'angle π/2
   a. Écrire z' en fonction de z
   b. Affixe d'un point image ; montrer d = a + 1
   c. Montrer qu'une figure est un losange
   d. Vérifier d − b = ((√3−1)/2)(1 − i) ; argument ; forme trigonométrique ; mesure d'angle (BI, BD)

## Problème : Étude de fonctions et calcul intégral (9 pts)

f définie sur [0, +∞[ par f(0)=0 et f(x)=2x ln x − 2x pour x>0
Courbe (C) dans repère orthonormé

1. Continuité à droite en 0

2. a. lim_{x→+∞} f(x) et lim f(x)/x ; interprétation
   b. lim_{x→0+} f(x)/x ; interprétation

3. f'(x) pour x>0 ; tableau de variations sur [0,+∞[

4. a. Résoudre f(x)=0 et f(x)=x sur ]0,+∞[
   b. Construire (C) (prendre e^{3/2} ≈ 4,5)

5. a. IPP : montrer ∫_1^e x ln x dx = (1+e²)/4
   b. En déduire ∫_1^e f(x) dx

6. a. Minimum de f sur ]0,+∞[
   b. En déduire : pour tout x>0, ln x ≥ (x−1)/x  (forme selon énoncé)

7. Restriction g de f à [1,+∞[
   a. Réciproque g^{-1} sur un intervalle J
   b. Construire (C_{g^{-1}})

8. h(x) = x³ + 3x si x≤0 ; h(x)=2x ln x − 2x si x>0
   a. Continuité en 0
   b. Dérivabilité à gauche en 0
   c. h dérivable en 0 ?

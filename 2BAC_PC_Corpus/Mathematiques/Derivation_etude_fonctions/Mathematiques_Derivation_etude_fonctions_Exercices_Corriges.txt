# EXERCICES — DÉRIVATION ET ÉTUDE DES FONCTIONS
Source : https://www.alloschool.com/element/122863 (Séance 5 — Exercices 1 à 6)

## Exercice 1
f(x) = x + 2/√(x+1)
a) D_f = ]−1, +∞[
b) lim_{x→+∞} f = +∞ ; lim_{x→−1+} f = +∞ → asymptote verticale x=−1
c) Asymptote oblique : lim (f(x)−x) = 0 → y=x asymptote oblique en +∞
d) Position : f(x)−x = 2/√(x+1) > 0 → courbe au-dessus de y=x
e) f'(x) = 1 − 1/[(x+1)^{3/2}]
Étudier le signe, variations, tangente en 0, construction, réciproque.

## Exercice 2
f(x) = (x−1)/√(x²−2x+2)
D_f = ℝ ; limites en ±∞ ; f' > 0 → croissante ; centre de symétrie ; réciproque.

## Exercice 3
f(x) = (√x − 1)/(x − 1) pour x≠1, f(1)=1/2 sur [0,+∞[
Continuité et dérivabilité en 1 ; f'(1)=−1/8 ; variations ; réciproque.

## Exercice 4
f(x) = x⁴/(x³+x²) pour x≠−1,0 ; f(0)=0
Asymptotes, variations, centre/axe, réciproque sur ]−1,0]

## Exercice 5
f(x) = x(x²+1)/(x²−1)
D_f, parité (impaire → symétrie O), limites, variations, concavité, tangente.

## Exercice 6
Partie 1 : g(x) = 1 + x/√(x²+1)
lim ±∞, g' > 0, g > 0
Partie 2 : f(x) = x − 1 + √(x²+1)
f' = g ; variations ; lim_{x→−∞} f = −1 ; asymptote oblique y=2x−1 en +∞

### Méthodes de résolution types
1. Factoriser / rationaliser pour les limites
2. Mettre au même dénominateur pour f'
3. Tableau de signes de f'
4. Pour asymptote oblique : diviser num/dén ou écrire f(x)=ax+b+ε(x)

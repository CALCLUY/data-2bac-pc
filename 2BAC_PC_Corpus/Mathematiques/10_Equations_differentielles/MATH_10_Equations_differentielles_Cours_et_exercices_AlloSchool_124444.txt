I- ÉQUATION DIFFÉRENTIELLE DE LA FORME  y' = a y + b
------------------------------------------------------------------------

1-1/ Propriété 1

Soit l'équation différentielle (E) : y' = a y + b.

Cas général (a ≠ 0) :
  l'ensemble des solutions de l'équation différentielle sont les fonctions
  de la forme
        f(x) = α·e^(a x) − b/a ,   α ∈ ℝ.

Cas particulier 1 (a = 0 ; b = 0) :
  l'équation est y' = 0 ; l'ensemble des solutions sont les fonctions
  constantes (f(x) = α, α ∈ ℝ).

Cas particulier 2 (a = 0 ; b ≠ 0) :
  l'ensemble des solutions sont les fonctions de la forme
        f(x) = b·x + α ,   α ∈ ℝ.

1-2/ Propriété 2

Soit l'équation différentielle y' = a y + b avec a ≠ 0, et
(x0 ; y0) ∈ ℝ².
Il existe une et une seule fonction qui est solution de l'équation et qui
vérifie la condition initiale  f(x0) = y0.

------------------------------------------------------------------------
II- ÉQUATION DIFFÉRENTIELLE DE LA FORME  y'' + a y' + b y = 0
------------------------------------------------------------------------

2-1/ Définition

L'équation différentielle de la forme
        (E) : y'' + a y' + b y = 0
telle que l'inconnue est la fonction y avec sa dérivée première y' et sa
dérivée seconde y'', s'appelle équation différentielle linéaire d'ordre 2
à coefficients constants sans second membre.

On appelle équation caractéristique de (E) l'équation
        r² + a r + b = 0 ,   r ∈ ℂ
et Δ = a² − 4b est le discriminant de l'équation caractéristique.

2-2/ Propriété — la solution générale de (E) dépend du signe de Δ.

Cas 1 : Δ > 0
  L'équation caractéristique a deux solutions réelles r1 et r2.
  Solution générale :
        y(x) = α·e^(r1·x) + β·e^(r2·x) ;  α, β ∈ ℝ.

Cas 2 : Δ = 0
  L'équation caractéristique a une solution réelle double r1.
  Solution générale :
        y(x) = (α·x + β)·e^(r1·x) ;  α, β ∈ ℝ.

Cas 3 : Δ < 0
  L'équation caractéristique a deux solutions complexes conjuguées
        r1 = p + q i  et  r2 = conj(r1) = p − q i.
  Solution générale :
        y(x) = (α·cos(q x) + β·sin(q x))·e^(p x) ;  α, β ∈ ℝ.

      (E') : y' + 2y = −e^(−3x)

3-2/ Exercice 2
1. Résoudre les équations différentielles suivantes :
      (E1) : 4y'' − 4y' + y = 0
      (E2) : y'' − 2y' + 5y = 0

3. Déterminer la solution qui vérifie les conditions
      g(0) = −3  et  g'(0) = −2

      (E1) : { y' = 2/x − 1 + 4x ;  y(1) = −7 }

      (E3) : { y'' + y' − 2y = 0 ;  y(0) = 0  et  y'(0) = −3 }

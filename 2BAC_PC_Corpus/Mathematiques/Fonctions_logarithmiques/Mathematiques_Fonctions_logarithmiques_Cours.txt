## I. Fonction logarithme népérien

### Définition
La primitive de f(x)=1/x sur ]0,+∞[ qui s'annule en 1 est la fonction ln :
ln : ]0,+∞[ → ℝ , (ln)'(x) = 1/x , ln(1)=0

### Conséquences
- Définie, dérivable, continue sur ]0,+∞[
- Strictement croissante car (ln)'=1/x > 0
- ln x < 0 si 0<x<1 ; ln 1 = 0 ; ln x > 0 si x>1

## II. Propriétés algébriques
Pour a>0, b>0, r∈ℚ :
ln(ab) = ln a + ln b
ln(1/a) = −ln a
ln(a/b) = ln a − ln b
ln(a^r) = r ln a
ln(√a) = (1/2) ln a

## III. Limites
lim_{x→+∞} ln x = +∞
lim_{x→0+} ln x = −∞  → asymptote verticale x=0
lim_{x→+∞} (ln x)/x = 0
lim_{x→+∞} (ln x)/x^n = 0 (n>0)
lim_{x→0+} x ln x = 0
lim_{x→0+} x^n ln x = 0 (n>0)
lim_{x→1} ln x /(x−1) = 1
lim_{x→0} ln(1+x)/x = 1

Branche parabolique direction Ox en +∞ (car ln x / x → 0).

## IV. Étude de f(x)=ln x
D_f = ]0,+∞[ ; continue ; f'>0 ; tableau :
x | 0+ ... 1 ... +∞
f | −∞ ↗ 0 ↗ +∞

## V. Fonction ln(u(x))
D_f : u(x)>0
[ln(u)]' = u'/u
[ln|u|]' = u'/u
Primitives de u'/u : ln|u| + c
Dérivée logarithmique de u : u'/u

## VI. Logarithme de base a
a ∈ ]0,1[ ∪ ]1,+∞[
log_a(x) = ln(x)/ln(a)
Cas a=e : log_e = ln
Cas a=10 : log = log₁₀ (logarithme décimal)
log(10^r)=r ; log(10)=1 ; log(1)=0

### Propriétés
log_a(xy)=log_a x + log_a y
log_a(1/x)=−log_a x
log_a(x/y)=log_a x − log_a y
log_a(x^r)=r log_a x
